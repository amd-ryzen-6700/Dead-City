# DEAD CITY

A first-person 3D zombie survival game that runs entirely in your browser.

**Play:** https://YOUR_USERNAME.github.io/dead-city/

## Controls
- **WASD** move · **Mouse** look · **Click** shoot · **RMB** aim
- **SHIFT** sprint · **SPACE** jump · **CTRL** crouch
- **R** reload · **F** flashlight · **G** grenade
- **E** loot · **TAB** inventory · **1–9, 0** weapons · **ESC** pause

## Co-op
Click **Host Co-op** or **Join Co-op**. You exchange two short codes (over any chat) and the game connects peer-to-peer via WebRTC — no server involved.

## Notes
- Works in Chrome, Edge, Firefox, Safari (desktop).
- Pointer lock, WebRTC, and clipboard all require HTTPS — GitHub Pages provides this.
- Not designed for mobile / touch.
- Built with Three.js (loaded from a CDN).
